# Plan: agent icons, Ring or Bar, one tab style per orientation (2026-10-12)

Spec: `docs/superpowers/specs/2026-10-12-tab-icons-design.md`. One branch (`feat/tab-icons`), one PR,
a commit per step, each with the test that holds it. Lands after the theme-editor PR (core 0.34.2),
so this one is core 0.35.0 (a new core export) and app 0.40.0.

## Steps

1. **`AgentIcon` (core).** Clawd, the OpenAI mark, the prompt, the cog; `size` prop, `currentColor`
   ink except Clawd's own orange. Test: each kind draws its mark; Clawd's pixels match the block
   art; an unknown kind is the prompt.
2. **Ring or Bar.** `termHost.tabMarks.indicators = ['ring', 'minimal']`, default `ring`. The
   Agents page offers two. Test: a stored `full` or `off` reads as Ring; the page lists two.
   (Plus the label "Bar" if the owner says yes to question 2.)
3. **The end slot.** `EndSlot` in `tabParts.tsx`: the ring in the close's place, the close on hover;
   no ring, the close as today. Both layouts use it. Test: the slot's states (ring, ring hovered,
   no ring in front, no ring behind).
4. **Classic with icons.** `TabStrip`: the icon (18 px, no box) at the left, the name centred in the
   rest, the end slot at the right. The Ring's old place before the name goes. Test: the strip draws
   no part of its own (the `tabParts` guard), and an e2e check that a Claude tab wears Clawd and a
   plain shell the prompt.
5. **The Icon band sidebar.** `TabSidebar`: the card with its 44 px band, the icon 18 px, name and
   folder, the end slot, the bar at the card's foot; the one in front tinted. Row height measured, the
   reorder tile following it.
6. **Powerline out.** Delete `promptGeometry.ts`, the Prompt branches, the Tab style row and pref,
   their tests and e2e checks. Core's Prompt and Full rules stay for Prism.
7. **Docs.** `docs/regression-rules.md` and CLAUDE.md where they name Powerline, Full or the ring's
   place; the two mockups into `docs/research/2026-10-12-tab-looks/`.
8. **Gate.** typecheck, lint, vitest, the full e2e; LOOK at the `.e2e-shots` of both strips and the
   Agents page; package and install for the owner; PR, merge after the owner's OK.
