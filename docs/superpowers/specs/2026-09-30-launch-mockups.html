Opening Prism Terminal with three Claude tabs

The same launch, four ways, on one clock. Scrub the bar to compare any moment. Claude takes about three seconds to come back in every version; what changes is what you see while it does.

0.00 s

What they share

The window opens with the tabs already in it, read from the saved tabs before the first frame. No start screen, no shell prompt and no half-typed command are ever shown on a tab that is coming back to Claude.

What it takes

A, card: the tab list sent with the window, and the shell's output held back until Claude's first paint. B, last screen: the same, plus each tab's screen saved when the app closes. C, skeleton: the same as A, with a drawn stand-in instead of a card.

Every tab, not just the one in front

Tabs in the background resume at the same time. Their spinner in the tab strip turns into the usual indicator when each is ready, so a click on one never lands on a loading screen that has already finished.
